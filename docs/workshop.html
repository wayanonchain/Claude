Твои боты: JUPITER + URAN

За один вечер ты поднимаешь на сервере двух цифровых сотрудников. Они работают круглосуточно и слушаются тебя прямо из Telegram — с телефона, ноута, откуда угодно. Программистом быть не нужно: копируешь команды по одной и нажимаешь Enter.

⏱ ~15 минут 🤖 2 агента 📱 управление из Telegram 🧑‍💻 без навыков кода
🪐

JUPITER — оператор

Твой главный бот. Разговаривает с тобой, понимает задачу и решает: сделать сам или поручить URAN.

☄️

URAN — исполнитель

Рабочие руки. Пишет код, делает документы, ищет информацию, автоматизирует.

🧭

Принцип Wayan: тишина = баг. Ты всегда видишь, что делает агент. И ничего важного — без твоего «ок».

✓

Зайти на сервер

Открой «Терминал» (на Mac/Linux он встроен; на Windows — приложение «PowerShell» или «Terminal»). Вставь команду, заменив ТВОЙ_IP на IP сервера от провайдера:

терминал
ssh root@ТВОЙ_IP

Спросит пароль — введи (символы не отображаются, это нормально), нажми Enter. Готово, ты «внутри» сервера.

1

Скачать репозиторий

Скачиваем готовую систему с гита Wayan Onchain. Скопируй весь блок целиком и вставь:

терминал
apt-get update && apt-get install -y git
git clone https://github.com/wayanonchain/Claude.git
cd Claude
📌

Это тот самый репозиторий. Создавать свой не нужно — ставишь прямо отсюда. Обновления потом прилетают сами командой jupiter-update.

2

Поставить JUPITER (оператор)

Одна команда — установщик сам сделает всё: создаст бота, поставит «движок», настроит роль.

терминал
sudo AGENT=jupiter bash install/install.sh

Идёт пару минут. В конце увидишь «Агент JUPITER установлен». Ничего больше нажимать не надо.

3

Поставить URAN (исполнитель)

То же самое для второго бота:

терминал
sudo AGENT=uran bash install/install.sh
4

Войти в Claude (по разу на бота)

Каждый бот логинится в твою подписку Anthropic. Вводи команды по одной:

терминал
sudo -u jupiter -H bash -lc '/home/jupiter/.local/bin/claude login'
sudo -u uran    -H bash -lc '/home/uran/.local/bin/claude login'

Появится ссылка — открой её в браузере, подтверди вход, скопируй код обратно в терминал. Сделай так для обоих.

5

Связать оператора и исполнителя

Чтобы JUPITER мог поручать задачи URAN:

терминал
sudo bash install/link-agents.sh
6

Подключить Telegram-ботов

1. В @BotFather командой /newbot создай два бота — получишь два токена.
2. У @userinfobot узнай свой Telegram ID (число).
3. Установи «мост» каждому боту:

терминал
sudo AGENT=jupiter bash install/telegram-install.sh
sudo AGENT=uran    bash install/telegram-install.sh

4. Впиши токен и свой ID (откроется простой редактор; вставь значения, сохрани Ctrl+O, Enter, выйди Ctrl+X):

терминал
sudo -u jupiter nano /home/jupiter/.config/jupiter/telegram.env
sudo -u uran    nano /home/uran/.config/uran/telegram.env

Внутри файла заполни две строки: TELEGRAM_BOT_TOKEN= (токен бота) и TELEGRAM_ALLOWED_IDS= (твой ID).

5. Запусти ботов:

терминал
sudo systemctl enable --now tg-jupiter
sudo systemctl enable --now tg-uran
🔒

Токен — это пароль бота. Никому не показывай, не пересылай в чаты, не выкладывай в интернет.

7

Проверка

Открой Telegram, найди своего бота JUPITER, напиши ему /start, потом любую задачу. Он ответит «🔄 Принял задачу, работаю…», покажет «печатает…», пришлёт результат и «✅ Готово».

📎

Если бот сделал файл (например HTML или отчёт) — он пришлёт его прямо в чат документом. Можно сразу пересылать.

∞

Дальше — с любого устройства

Всё управление — из Telegram, с телефона или ноута, откуда угодно. Сервер один, устройств сколько хочешь.

Обновить ботов (когда в репозитории что-то улучшат):

терминал
sudo jupiter-update
sudo uran-update
🛟

Если что-то не так

СимптомЧто сделать
Бот не отвечаетНапиши ему /start. Не помогло — на сервере: sudo systemctl restart tg-jupiter
«Ошибка агента» на каждое сообщениеБот не залогинен — повтори Шаг 4, затем перезапусти: sudo systemctl restart tg-jupiter
Бот «молчит» / ничего не делаетДля URAN включи полную автономию: в его telegram.env впиши CLAUDE_PERMISSION_ARGS=--dangerously-skip-permissions и перезапусти
Файл не прислалПопроси «сохрани и пришли файл». Логи: sudo journalctl -u tg-jupiter -n 40
