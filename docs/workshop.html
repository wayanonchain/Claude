VPS стоит пару долларов в месяц. При заказе выбери «Ubuntu 22.04». Провайдер пришлёт IP, логин root и пароль.

Что такое VPS и где его взять?
VPS — это арендованный компьютер в дата-центре, который работает круглосуточно. Боты живут на нём и отвечают тебе всегда, даже когда твой ноут выключен. Арендуют у хостинг-провайдеров (Hetzner, DigitalOcean, Timeweb, Aeza и др.) — при заказе выбираешь «Ubuntu 22.04», оплачиваешь, получаешь доступ.

Зайти на сервер

Открой Терминал (Mac/Linux — встроенный; Windows — «PowerShell»). Замени ТВОЙ_IP на адрес сервера:

терминал
ssh root@ТВОЙ_IP

Спросит пароль — введи (символы не видны, это норма), Enter. Ты на сервере.

Что такое SSH?
SSH — это безопасный способ удалённо управлять сервером из своего терминала, как будто ты сидишь прямо за ним. Ты печатаешь команды у себя, а выполняются они на сервере.
Где найти ТВОЙ_IP?
IP — это адрес сервера, набор цифр вида 203.0.113.45. Его присылает провайдер VPS на почту сразу после оплаты, и он есть в личном кабинете провайдера в карточке сервера (поля «IP address», «IPv4»).
Что такое root?
root — главный пользователь сервера с полными правами (как «администратор»). Логин root и пароль к нему тоже в письме/кабинете провайдера.
Как открыть Терминал?
Mac: нажми Cmd+Space, набери «Терминал», Enter.
Windows: меню Пуск → набери «PowerShell» → открой.
Linux: Ctrl+Alt+T. Терминал — это окно, куда вставляют команды и жмут Enter.

2

Поставить JUPITER и URAN

По одной команде на бота. Установщик делает всё сам:

терминал
sudo AGENT=jupiter bash install/install.sh
sudo AGENT=uran    bash install/install.sh

Каждая идёт пару минут. В конце — «Агент … установлен».

Что такое sudo и install.sh?
sudo — «выполнить с правами администратора» (нужно для установки программ). install.sh — готовый скрипт-установщик из репозитория: он сам ставит движок, создаёт бота, настраивает папки. Тебе ничего вручную делать не нужно.
Это безопасно?
Да. Скрипт ставит только нужное (Node.js, Claude Code), не трогает твои личные данные и ничего не удаляет. Весь его код открыт в репозитории — можно посмотреть.

5

Подключить Telegram-ботов

1. В @BotFather командой /newbot создай два бота → получишь два токена.
2. У @userinfobot узнай свой Telegram ID (число).
3. Установи «мост» каждому боту:

терминал
sudo AGENT=jupiter bash install/telegram-install.sh
sudo AGENT=uran    bash install/telegram-install.sh

4. Впиши токен и ID (редактор nano: вставь значения → сохрани Ctrl+O, Enter → выйди Ctrl+X):

терминал
sudo -u jupiter nano /home/jupiter/.config/jupiter/telegram.env
sudo -u uran    nano /home/uran/.config/uran/telegram.env

Две строки: TELEGRAM_BOT_TOKEN= (токен) и TELEGRAM_ALLOWED_IDS= (твой ID).

5. Запусти ботов:

терминал
sudo systemctl enable --now tg-jupiter
sudo systemctl enable --now tg-uran
🔒

Токен — это пароль бота. Никому не показывай, не пересылай в чаты.

Где взять токен бота?
Напиши @BotFather в Telegram команду /newbot, придумай имя и ник бота — он пришлёт длинную строку вида 123456:AAE.... Это и есть токен. Создай так двух ботов — для JUPITER и для URAN.
Что такое Telegram ID и где его взять?
Это твой личный номер в Telegram (число). Напиши @userinfobot — он пришлёт твой Id. Нужен, чтобы бот отвечал только тебе.
Как пользоваться редактором nano?
nano — простой текстовый редактор прямо в терминале. Стрелками подведи курсор к нужной строке, впиши значение после =. Сохранить: Ctrl+O, затем Enter. Выйти: Ctrl+X.

1

Установить Claude Code

Открой «Терминал» (Cmd+Space → набери «Терминал»). Вставь:

Терминал (Mac)
curl -fsSL https://claude.ai/install.sh | bash

Если попросит установить «Command Line Tools» — согласись (кнопка Install). После установки закрой и открой Терминал заново.

Что такое Терминал на Mac?
Это встроенное приложение, куда вводят текстовые команды. Открыть: Cmd+Space → набери «Терминал» → Enter. Команды отсюда копируешь кнопкой «копировать» и вставляешь туда (Cmd+V), затем Enter.
Что такое «Command Line Tools»?
Это бесплатный набор инструментов от Apple (включает git). macOS сам предложит их поставить при первой надобности — просто нажми Install.

Терминал (Mac)
claude

Скачать репозиторий

Терминал (Mac)
git clone https://github.com/wayanonchain/Claude.git ~/Claude

Если git не найден — Mac сам предложит поставить «Command Line Tools», согласись и повтори.

4

Создать агента JUPITER

Заводим рабочую папку и кладём в неё роль оператора:

Терминал (Mac)
mkdir -p ~/jupiter/.claude
cp ~/Claude/templates/jupiter.md ~/jupiter/.claude/CLAUDE.md
cp -r ~/Claude/skills ~/jupiter/.claude/skills
5

Запустить и настроить

Терминал (Mac)
cd ~/jupiter
claude

Внутри чата набери /onboarding — агент сам расспросит тебя и заполнит профиль за 5–10 минут. Готово, можешь давать задачи прямо в терминале.

6

Второй агент URAN (по желанию)

Повтори то же во второй папке с ролью исполнителя:

Терминал (Mac)
mkdir -p ~/uran/.claude
cp ~/Claude/templates/uran.md ~/uran/.claude/CLAUDE.md
cp -r ~/Claude/skills ~/uran/.claude/skills
cd ~/uran && claude

Открой второе окно Терминала для URAN. Так оператор и исполнитель работают параллельно.
