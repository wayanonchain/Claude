# Архив — коммерческий слой курса wayan-claude-md

<!-- Часть проекта Wayan (автор: Wayan Onchain, @wayan_onchain) -->

Здесь лежат материалы коммерческого курса (треки **CLAUDE PRO** / **CLAUDE BIZ** /
nontech), вынесенные из основного дерева при переходе репозитория на
**универсальную двухагентную архитектуру JUPITER + URAN** (модель EdgeLab Day-1).

Ничего не удалено — материалы сохранены целиком на случай возврата к курсовому
формату. История изменений целиком доступна в `git log`.

## Что внутри

| Файл / папка | Что это | Трек |
|---|---|---|
| `COURSE.md` | Программа двух платных продуктов | PRO + BIZ |
| `GLOBAL-NONTECH.md`, `WORKSPACE-NONTECH.md` | Гайды без git/кода | PRO + BIZ |
| `global-claude-nontech.md`, `rules-nontech.md`, `user-nontech.md` | Шаблоны non-tech | PRO + BIZ |
| `workspace-pro.md` | Рабочий CLAUDE.md контент-агента | PRO |
| `workspace-biz.md` | Рабочий CLAUDE.md SMB-оркестратора | BIZ |
| `skills-brand-voice/` | Скилл «голос бренда» | PRO |
| `skills-smb-orchestra/` | Скилл «оркестратор 5 SMB-ролей» | BIZ |
| `marketer-pro-filled.md` | Пример: маркетолог Маша | PRO |
| `smb-biz-filled.md` | Пример: владелец бизнеса Артём | BIZ |

## Почему вынесено

Цель основного репозитория — **универсальная система цифровых сотрудников**, а не
набор узкоспециализированных ролей. PRO/BIZ-роли (контент-маркетинг, SMB-оркестр)
заменены двумя универсальными агентами: **JUPITER** (оператор/шлюз/маршрутизация)
и **URAN** (исполнитель: код, исследования, документы, автоматизация).
