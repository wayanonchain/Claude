# SMB Orchestra -- Multi-Agent System for Small Business

> Часть курса [wayan-claude-md](../../README.md) от [Wayan Onchain](https://t.me/wayan_onchain).
> Трек: **CLAUDE BIZ**. Базовый скилл для SMB-оркестратора (см. [examples/smb-biz-filled.md](../../examples/smb-biz-filled.md)).
> Якорный нарратив: [Claude for Small Business](https://shazoo.ru/2026/05/14/183978/) (Anthropic, 14 мая 2026).

## Когда использовать

- Запуск Claude в малом бизнесе (1--10 человек) впервые
- Замена операционных ролей (admin / контент-менеджер / клиент-сервис)
- Масштабирование: новые задачи -> новый специалист в оркестр
- Окупаемость: твой бизнес должен экономить ≥ стоимости подписки за первый месяц

## Архитектура

```
                    Оператор (владелец бизнеса)
                            │
                            ▼
                    ┌───────────────┐
                    │  Координатор  │  <- этот скилл
                    └───────┬───────┘
                            │
        ┌──────────┬────────┼────────┬──────────┐
        ▼          ▼        ▼        ▼          ▼
    Маркетинг  Продажи  К-сервис  Отчёты  Документы
```

## 5 специалистов

### 1. Маркетинг-агент
**Что:** посты в TG/VK/Instagram, email-рассылка, контент-конвейер 30+ постов/мес, лендинги в Tilda
**Стек:** SMMplanner / SmmBox / Senler, Canva (через Claude connector), Tilda API
**Триггер:** задача от оператора, Routine «контент-конвейер на неделю»

### 2. Продажный агент
**Что:** квоты, follow-up, объяснение продукта, переговоры с теплыми лидами
**Стек:** AmoCRM / Битрикс24 / HubSpot, Telegram-бот, WhatsApp Business
**Триггер:** новый лид в CRM, сообщение от клиента, Routine «follow-up по непрочитанным»

### 3. Клиент-сервис
**Что:** ответы по базе знаний, расписание, замены, тарифы, FAQ
**Стек:** TG/WhatsApp бот, Notion (база знаний), CRM (для контекста клиента)
**Триггер:** входящее сообщение в бот клиентов

### 4. Отчёт-агент
**Что:** ежедневный отчёт (9:00) -- лиды, оплаты, отмены, SLA. Недельный -- по программам/каналам
**Стек:** CRM API, бухгалтерия (1С / QuickBooks), Google Sheets, TG-бот для отправки
**Триггер:** Routine «09:00 daily report», «17:00 mid-day update», «Sun 18:00 weekly»

### 5. Документ-агент
**Что:** счета, акты, выписки, договоры с подрядчиками, простые правовые документы
**Стек:** 1С / QuickBooks connector (Claude for SMB, 14 мая 2026), Docusign, Google Workspace
**Триггер:** задача от оператора («сгенери счёт на 78К для ООО Ромашка»)

## Процесс настройки оркестратора

### Шаг 1: интервью оператора (15 минут)

Координатор-агент через диалог собирает:
- Ниша бизнеса (онлайн-школа / e-com / B2B-услуги / агентство / прочее)
- Команда (соло / 2--5 / 6--10)
- Стек:
  - CRM: AmoCRM / Битрикс24 / HubSpot / NoCRM / нет
  - Бухгалтерия: 1С / QuickBooks / Эльба / самописное / нет
  - Мессенджеры клиентов: TG-бот / WhatsApp Business / директ-чаты / нет
  - Сайт: Tilda / Wordpress / самописный / нет
  - Планировщик контента: SMMplanner / SmmBox / Senler / руками
- Главные KPI квартала (выручка / лиды / удержание / NPS)
- Какие роли хочет автоматизировать первыми (1--3 из 5)

### Шаг 2: генерация файлов

- `~/.claude/CLAUDE.md` -- из `templates/global-claude-nontech.md`
- `.claude/CLAUDE.md` (workspace) -- из `templates/workspace-biz.md`, заполнен под бизнес
- `core/USER.md` -- из `templates/user-nontech.md`
- `core/rules.md` -- из `templates/rules-nontech.md` с лимитами оператора
- `core/smb-stack.md` -- ваш стек, источники правды
- `core/MEMORY.md` -- база клиентов, поставщиков, программ (импорт из CRM)
- `tools/TOOLS.md` -- API-токены, ссылки на сервисы
- 5 поддиректорий для специалистов (опционально): `agents/marketing/`, `agents/sales/`, ...

### Шаг 3: подключение коннекторов (Claude for Small Business)

По состоянию на 14 мая 2026 Anthropic выпустила 15 готовых connector-сценариев:

| Сервис | Что делает | Кому |
|---|---|---|
| QuickBooks | счета, отчёты P&L, payroll | бухгалтерия / финансы |
| PayPal | приёмы платежей, рефанды | e-com / услуги |
| HubSpot | CRM, маркетинг-автоматизация | продажи / маркетинг |
| Canva | дизайн постов, презентаций | маркетинг |
| Docusign | электронные подписи договоров | документы / правовое |
| Google Workspace | Gmail, Docs, Sheets, Calendar | везде |
| M365 | Outlook, Word, Excel | везде (корпоративные) |

В России (где QuickBooks не везде применим) -- аналоги через API: 1С, Эльба, AmoCRM, Битрикс24.

### Шаг 4: Routines (ночные пайплайны)

Минимальный набор для любого SMB:

```yaml
routines:
  - name: daily-report
    schedule: "0 9 * * 1-5"   # будни в 9:00
    agent: report-agent
    action: |
      Собери метрики за вчера:
      - новые лиды (CRM)
      - оплаты (бухгалтерия)
      - отмены (CRM)
      - просрочки SLA (мессенджер-бот логи)
      Отправь оператору в TG.

  - name: mid-day-followup
    schedule: "0 17 * * 1-5"  # будни в 17:00
    agent: sales-agent
    action: |
      Собери follow-up'ы, которые нужно сделать до конца дня.
      Отправь оператору в TG.

  - name: backup-crm
    schedule: "0 22 * * *"   # каждый день в 22:00
    agent: report-agent
    action: |
      Выгрузи Битрикс24 в Google Drive (зашифрованный архив).

  - name: weekly-summary
    schedule: "0 18 * * 0"   # воскресенье 18:00
    agent: report-agent
    action: |
      Недельная сводка с разбивкой по программам/каналам/преподавателям.
      Подготовь как HTML через present.
```

### Шаг 5: метрика окупаемости

В `decisions.md` фиксируй каждый месяц:
- Какие роли заменил (списком)
- Сколько стоит подписка Claude Pro/Team
- Сколько стоил бы найм (рыночная зарплата)
- ROI = (экономия - подписка) / подписка × 100%

Цель курса BIZ: окупаемость 1--2 месяца. Если не окупается -- эскалация к оператору +
анализ что не так (см. Урок 16 «Расчёт ROI и масштабирование»).

## Зоны ответственности

| Зона | Кто решает |
|---|---|
| Стратегия (продукт, цены, ниша) | только оператор |
| Сделки > {{ПОРОГ}} ₽ | оператор + оркестратор |
| Стандартные операции | оркестратор + специалист |
| Контентные драфты | специалист, оператор ревьюит |
| Отчёты, документы внутренние | специалист, авто |

## Anti-patterns

| Делать | Не делать |
|---|---|
| 5 специалистов с чёткими зонами | Один «универсал» -- путается |
| Routines под повторяющиеся задачи | Запускать руками каждое утро |
| Эскалация после 2 провалов | «Я попробую ещё раз»  ×10 |
| voice.md и smb-stack.md как @include | Хардкод реквизитов в CLAUDE.md |
| API-ключи в `.env` | API-ключи в CLAUDE.md / в чате |
| Источник правды -- CRM | Источник правды -- память агента |

## Integration

- `brand-voice` -- если оператор сам пишет контент, маркетинг-агент использует его voice
- `present` -- отчёт-агент рендерит еженедельный отчёт как HTML
- `self-compiler` -- координатор фиксирует решения и патерны в decisions.md
- `onboarding` (track=BIZ) -- запускает smb-orchestra после первичной настройки

## Что НЕ делает этот скилл

- Не пишет код агентов сам -- это не дев-инструмент
- Не интегрируется в обход API (никаких хаков рекламных кабинетов)
- Не отправляет ничего клиенту без явного «ок» оператора по сценарию
- Не работает без хотя бы одного источника правды (CRM или Google Sheets минимум)
