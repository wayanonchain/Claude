# JUPITER Installer

One-agent Claude Code setup for `wayanonchain/Claude`.

## Install

```bash
git clone https://github.com/wayanonchain/Claude.git
cd Claude
sudo bash install/install.sh
```

## Login

```bash
sudo -u jupiter -H bash -lc '/home/jupiter/.local/bin/claude login'
```

## Start

```bash
jupiter
```

## Update

```bash
jupiter-update
```
